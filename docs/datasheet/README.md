# Datasheets

Manufacturer PDFs are kept locally and are not included in the repository. Links to PDF files in the control-card documents refer to those local copies and will not work in a fresh clone until the files are obtained separately.

Obtain current documents from the manufacturers or the supplier product pages in the [control-card BOM](../../hardware/STM32_control_card/STM32_Control_Card_BOM.md). Key starting points:

- [STM32G474 product page](https://www.st.com/en/microcontrollers-microprocessors/stm32g474qe.html) and [STM32G4 documentation](https://www.st.com/en/microcontrollers-microprocessors/stm32g4-series.html#documentation)
- [TI ISO1042](https://www.ti.com/product/ISO1042), [UCC33421](https://www.ti.com/product/UCC33421), and [UCC12050](https://www.ti.com/product/UCC12050)
- [Murata GRM21BZ71A226ME15 reference sheet](https://search.murata.co.jp/Ceramy/image/img/A01X/G101/ENG/GRM21BZ71A226ME15-01A.pdf)
- [Waveshare 1.3-inch LCD HAT](https://www.waveshare.com/wiki/1.3inch_LCD_HAT)
