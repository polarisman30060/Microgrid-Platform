# Hardware Standards & Control Power Architecture

## Target EDA & PCB Architecture

- **Primary EDA Platform:** EasyEDA Pro
- **Hybrid Multi-Layer Strategy:**
  - **4-Layer Control Daughter Cards:** Noise-immune mixed-signal PCBs housing the local microcontroller, isolated analog telemetry conditioners, and isolated CAN transceivers.
  - **2-Layer Signal Power Stages:** Power interface boards carrying gate drive traces, local snubbers, and current sensors.
  - **Stacked Copper Busbars:** Heavy current delivery paths bypass PCB copper planes where currents exceed PCB trace limits, utilizing M4-bolted stacked copper busbars and chassis-mounted isolated power blocks.
- **Inter-Board Connector Interface:** Standardized dual-row `2.54mm` pitch headers routing isolated logic power, PWM gate signals, CAN buses, and differential telemetry between the 4-layer daughter card and 2-layer power stage.

## Standardized Module Microcontroller

- **MCU Part Number:** STMicroelectronics **STM32G474QET6** (and compact `STM32G474CE`/`RE` packages for per-panel Solar MPPT nodes)
- **Key Peripherals Utilized:**
  - **HRTIM1 (High-Resolution Timer):** `184 ps` clock resolution for complementary PWM generation, dead-time insertion, and sub-microsecond hardware fault overrides.
  - **FDCAN Controller (Classic CAN Mode):** Configured strictly in **Classical CAN 2.0B mode** (`FDCAN_FRAME_CLASSIC`, non-FD) at `500 kbps` using standard 11-bit identifiers (`0x000`–`0x7FF`) via isolated transceivers (draft control-card baseline: `TI ISO1042DWV`, `5 kVrms`; see [`../hardware/STM32_control_card/STM32_Control_Card_Mechanical_and_Power.md`](../hardware/STM32_control_card/STM32_Control_Card_Mechanical_and_Power.md)) for full compatibility with the Coordinator's ESP32-S3 TWAI interface.
  - **12-Bit ADCs:** Synchronized sampling of isolated voltage and current channels.
- **Local Diagnostics Display:** Directly mounted **Waveshare `1.3-inch` SPI IPS LCD + keypad HAT** (`ST7789`, `240×240`, replacing the earlier `1.3-inch` OLED concept; see [`../hardware/STM32_control_card/STM32_Control_Card_Architecture.md`](../hardware/STM32_control_card/STM32_Control_Card_Architecture.md)) on each accessible control card to display `GlobalNodeID`, firmware version, permanent serial number, and active operating states without external diagnostic tools (omitted on inaccessible roof-mounted Solar MPPT modules).

## System Lifeline Control Power Bus (Split Diode-OR'd `24 VDC` Auxiliary Bus)

See [`System_Safety_and_Protection_Architecture.md`](./System_Safety_and_Protection_Architecture.md) for the complete specification, E-Stop safety relay chain, and overcurrent coordination table.

- **Control Bus Specification:** Regulated, galvanically isolated **24.0 VDC** (`22.8–25.2 VDC` normal, clamped `< 30 V`) DC distribution backbone generated by isolated `48 V → 24 VDC` supplies inside each Battery Storage Module with output droop and Ideal-Diode OR-ing (`Black Start` capable, zero-ms multi-battery failover, zero phase-sync requirement).
- **Per-Tap Short Isolation:** Every module taps the `24 VDC` bus through its own fast fuse or active current-limiting eFuse (`1–3 A`) so a local fault never collapses control power for other nodes.
- **Dual-Rail Split:**
  - **`AUX_LOGIC_24V` (Un-interruptible Lifeline):** Powers the ESP32-S3 Coordinator, all STM32G474 daughter cards (with optional per-host `24 V → 24 V` isolated DC-DC brick if isolated `GND_CTRL` is desired), isolated CAN transceivers, and diagnostics. **Never shut down during local module faults or E-Stop** so faults are always logged and reported.
  - **`AUX_COIL_24V` (Safety-Interlocked Rail):** Routed through the hardwired latched E-Stop / `96 V` DC GFDI Safety Relay to feed all `24 VDC` contactor coils, fail-safe `NC` `400 V` discharge relays, module `HRTIM1_FLT3` (`ESTOP_OK`) lines, and NEC 690.12 rooftop Solar Rapid Shutdown keep-alive.

## Standardized Dual-Contactor & Hardware Latch Topology

Every power module interfacing with the `96VDC Energy Bus` utilizes an identical dual-contactor arrangement using true DC-rated hermetically sealed contactors (`≥ 150 VDC`, with integral auxiliary mirror contacts) powered by `AUX_COIL_24V`:

| Function | STM32G474 Pin (Draft Control Card) | Low-Side Driver | Purpose |
| :--- | :--- | :--- | :--- |
| **Pre-Charge Bypass Contactor (`Q_PRE`)** | `PD2` (`CONT_CMD1`, `J1:32`) | `NVD5117PL` / `IRLR2905` (DPAK) | Closes in series with a chassis-mounted ceramic power resistor (`10Ω–50Ω`, 50W) to equalize bus and module capacitance (`ΔV ≤ 1.5V`). |
| **Main Isolation Contactor (`Q_ISOL`)** | `PD7` (`CONT_CMD2`, `J1:33`) | `NVD5117PL` / `IRLR2905` (DPAK) | Closes once pre-charge completes to carry continuous power; opens immediately upon local hardware or software fault trips. |

*Note:* Earlier hardware baselines listed `PC6`/`PC7`; the draft [STM32 Control Card Pinout](../hardware/STM32_control_card/STM32_Control_Card_Pinout.md) reassigned `PC6`/`PC7` to `HRTIM1_CHF1/2` (required by the Generator module) and placed up to three contactor commands on `PD2`, `PD7`, and `PD14` (`J1:32–34`) with auxiliary feedbacks on `PE3–PE5` (`J1:35–37`).

- **Flyback Protection:** High-speed `MUR120` Schottky diodes placed directly across every contactor coil.
- **Degraded Mode Contactor Behavior:** Loss of CAN communication from the Coordinator (`> 500 ms`) transitions the module into `DEGRADED_AUTONOMOUS` mode rather than opening `Q_ISOL`, provided local electrical and thermal parameters remain within safe bounds.
