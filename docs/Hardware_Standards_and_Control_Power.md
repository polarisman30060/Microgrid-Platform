# Hardware Standards & Control Power Architecture

## Target EDA & PCB Architecture

- **Primary EDA Platform:** EasyEDA Pro
- **Hybrid Multi-Layer Strategy:**
  - **4-Layer Control Daughter Cards:** Noise-immune mixed-signal PCBs housing the local microcontroller, isolated analog telemetry conditioners, and isolated CAN transceivers.
  - **2-Layer Signal Power Stages:** Power interface boards carrying gate drive traces, local snubbers, and current sensors.
  - **Stacked Copper Busbars:** Heavy current delivery paths bypass PCB copper planes where currents exceed PCB trace limits, utilizing M4-bolted stacked copper busbars and chassis-mounted isolated power blocks.
- **Inter-Board Connector Interface:** Standardized dual-row `2.54mm` pitch headers routing isolated logic power, PWM gate signals, CAN buses, and differential telemetry between the 4-layer daughter card and 2-layer power stage.

---

## Standardized Module Microcontroller

- **MCU Part Number:** STMicroelectronics **STM32G474QET6** (exclusively across all module daughter cards)
- **Key Peripherals Utilized:**
  - **HRTIM1 (High-Resolution Timer):** `184 ps` clock resolution for complementary PWM generation, dead-time insertion, and sub-microsecond hardware fault overrides.
  - **CAN-FD / CAN 2.0B Controller:** Operating in standard 11-bit `500 kbps` mode via isolated transceivers (`TI ISO1050`).
  - **12-Bit ADCs:** Synchronized sampling of isolated voltage and current channels.
- **Local Diagnostics Display:** Onboard `1.3-inch` OLED display module mounted on each enclosure chassis to display Node ID, firmware version, permanent serial number, and active operating states without external diagnostic tools.

---

## System Lifeline Control Power Bus (`30VAC @ 5kHz`)

- **Control Bus Specification:** Continuous, un-interruptible **30VAC @ 5kHz** square-wave distribution backbone.
- **Generation Source:** Generated by local push-pull auxiliary inverter stages inside the Battery Storage Modules pulling directly from local cell strings (`Black Start` capable).
- **Un-interruptible Operation Rule:** **The 30VAC @ 5kHz control bus shall never be shut down during local module faults.** Maintaining continuous control power keeps the ESP32-S3 Supervisor and all STM32G474QE daughter cards online to log and report fault conditions.

---

## Standardized Dual-Contactor & Hardware Latch Topology

Every power module interfacing with the `96VDC Energy Bus` utilizes an identical dual-contactor arrangement powered by a local `24VDC` rail rectified from the `30VAC @ 5kHz` lifeline:

| Function | STM32G474QE Pin | Low-Side Driver | Purpose |
| :--- | :--- | :--- | :--- |
| **Pre-Charge Bypass Contactor (`Q_PRE`)** | `PC6` | `NVD5117PL` / `IRLR2905` (DPAK) | Closes in series with a chassis-mounted ceramic power resistor (`10Ω–50Ω`, 50W) to equalize bus and module capacitance (`ΔV ≤ 1.5V`). |
| **Main Isolation Contactor (`Q_ISOL`)** | `PC7` | `NVD5117PL` / `IRLR2905` (DPAK) | Closes once pre-charge completes to carry continuous power; opens immediately upon local hardware or software fault trips. |

- **Flyback Protection:** High-speed `MUR120` Schottky diodes placed directly across every contactor coil.
- **Degraded Mode Contactor Behavior:** Loss of CAN communication from the Supervisor (`>1500 ms`) transitions the module into `DEGRADED` mode rather than opening `Q_ISOL`, provided local electrical and thermal parameters remain within safe bounds.
